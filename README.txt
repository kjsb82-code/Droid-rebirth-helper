DROID REBIRTH HELPER

Files:
- index.html
- data.js
- manifest.webmanifest
- sw.js
- icons

For a normal phone-app experience, host this folder on any HTTPS static host, open it in Chrome on Android, then choose “Add to Home screen” / “Install app”.

The app:
- covers Cycles 1–5 and Rebirths 1–40
- searches droids
- shows every rebirth where the droid is required
- shows required variant
- shows KEEP/SELL based on future requirements in the selected cycle
- shows whether your selected owned variant is high enough
- remembers current cycle/rebirth on the device
- works offline after first load when hosted as a PWA

Note: Kyber is included for Rebirths 36–40 because it is present in the current requirement data.
